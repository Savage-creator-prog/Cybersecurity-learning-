Topics Learned

1. pwd (Print Working Directory)

Purpose

Displays my current location in the Linux file system.
What I Learned

* pwd tells me exactly where I am in the file system.
* It helps me understand my current working directory before navigating elsewhere.

⸻

2. find Command

Purpose

Searches for files and directories based on specific conditions.
Breakdown

* find . – Search from the current directory.
* -type f – Search only for files.
* -size 1033c – Find files that are exactly 1033 bytes.
* ! -executable – Exclude executable files.

What I Learned

Instead of manually checking every folder, I can use find to locate the exact file I need. This is a faster and more efficient approach, especially when working with many files.
